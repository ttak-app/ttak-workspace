# 웹 작업

저장소 루트의 [Codex 지침](../../AGENTS.md), [공통 코딩 컨벤션](../../docs/rules/coding-convention.md),
[React·TypeScript 컨벤션](../../docs/rules/web-coding-convention.md), [Git 컨벤션](../../docs/rules/git-convention.md)을 적용한다.
이 폴더는 React 랜딩 페이지다. Swift의 타입·상태·명명 규칙을 적용하지 않는다.
웹 코드 수정 후 저장소 루트의 `npm run format:web`로 형식을 맞추고 `npm run format:check:web`로 검사한다.
