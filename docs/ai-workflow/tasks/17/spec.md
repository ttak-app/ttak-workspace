# 작업 명세: 디자인 시스템 구축

## 연결 정보

- 이슈: #17 / https://github.com/ttak-app/ttak-workspace/issues/17
- 브랜치: feat/design-system/#17
- specRevision: 2

## 목적

최신 랜딩의 실제 스타일을 근거로 재사용 가능한 디자인 기초 토큰과 사용 지침을 구축한다.

## 작업 범위

### 포함

- 최신 랜딩 CSS의 cascade와 반응형 규칙, 기존 토큰 초안, JavaScript 모션 조사
- 컬러, 타이포그래피, 간격, 반경, 경계선, 그림자, 블러, 투명도, 모션, 레이아웃 기준
- 원시값과 의미 토큰, 공통 JSON 원본에서 웹 CSS와 공유 가능한 macOS 기초 토큰, 목록과 미리보기 생성, 참조와 생성물 일관성 검사
- 저장소에서 열 수 있는 분석 근거, 대비와 폰트 fallback 및 reduced-motion 확인 기록

### 제외

- UI 컴포넌트 제작과 컴포넌트 라이브러리, 기존 화면 전체 마이그레이션과 리디자인
- 새 폰트, 다크 모드, Figma 작업, 새 라이브러리와 CI 정책
- push, PR 생성, merge

## 설계 결정

- `design-system/tokens.json`을 관리 원본으로 두며 이름은 `ttak-` CSS 접두사로 출력한다.
- 원본의 각 토큰에 종류, 값, 용도, 근거와 상태를 기록한다. 의미 토큰은 원시값을 참조한다.
- `tools/design-tokens/`의 Node ESM 도구가 CSS와 Markdown 목록을 생성하고 잘못된 참조와 오래된 생성물을 검사한다. 외부 의존성은 추가하지 않는다.
- 토큰은 opt-in이다. 앱의 전역 스타일에 자동으로 적용하지 않으며 새 컴포넌트나 패키지를 만들지 않는다.
- `docs/design-system/reference/`에 조사 시점 CSS와 기존 초안, 모션 발췌를 보관한다. 출처별 해시와 실제 적용값을 분석 문서에 남긴다.
- 반응형 토큰은 원본 media query의 경계와 cascade를 유지한다. breakpoint 변수는 media query에서 직접 사용할 수 없다는 제한을 문서화한다.
- 상태와 데이터 흐름: 제품 상태 변경 없음. JSON → 검증 및 참조 해석 → CSS와 목록 생성.
- 예외 처리: 참조 누락과 순환, 중복 CSS 변수, 잘못된 원본 구조 및 생성물 불일치는 실패로 종료한다.

## 완료 조건

- AC-1: 실제 사용값과 기존 초안의 차이, 반응형 덮어쓰기 및 근거를 저장소 문서로 추적할 수 있다.
- AC-2: 요청한 기초 토큰이 공통 JSON, 웹 CSS, macOS용 공유 색상과 수치로 제공되고 각 토큰의 이름, 값, 용도와 근거가 기록된다.
- AC-3: JSON 수정 후 재생성이 가능하며 참조 누락, 순환과 생성물 불일치를 검사할 수 있다.
- AC-4: 대표 색상 대비, 폰트 fallback, 반응형 값과 reduced-motion 처리를 확인하고 미확정 사항을 문서화한다.
- AC-5: 컴포넌트 및 기존 앱 화면 변경 없이 목적별 작은 커밋으로 작업을 기록하고 사용자가 볼 수 있는 시각적 미리보기를 제공한다.

## 검증 방법

| 완료 조건 | 확인 방법 | 기대 결과 |
|---|---|---|
| AC-1 | 원본 해시 대조와 cascade 조사, 브라우저 computed style | 초안과 현재값의 차이를 근거로 설명 가능 |
| AC-2 | 생성 토큰 목록과 CSS, 브라우저 CSS 파싱 | 범위 충족 및 문법 오류 없음 |
| AC-3 | 생성 도구 check와 잘못된 입력 회귀 검사 | 정상 입력 통과 및 오류 입력 거부 |
| AC-4 | 대비 계산, 여러 viewport와 reduced-motion 관찰 | 실제 결과 및 사용 제한 기록 |
| AC-5 | Git diff와 커밋 기록, 웹 검사와 macOS 빌드, 미리보기 화면 확인 | 범위 준수 및 기존 빌드 유지, 시각적 확인 가능 |

## 미결정 사항

- 다크 모드, 신규 폰트, macOS의 실제 화면별 타이포그래피와 CSS 효과 변환은 후속 논의 대상이며 이번 작업을 막지 않는다.
- 기존 낮은 대비 텍스트의 대체 색상 확정은 시각 변경이므로 후속 검토로 남긴다.
