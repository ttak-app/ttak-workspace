# 작업 명세: CodeRabbit 세팅

## 연결 정보

- 이슈: #7 / https://github.com/ttak-app/ttak-workspace/issues/7
- 브랜치: chore/coderabbit-setting/#7
- specRevision: 1

## 목적

Keeply의 CodeRabbit 설정을 참고해 Ttak의 PR 리뷰를 보완한다.
기존 Swift와 웹 규칙을 각각 적용하고 새로운 코딩 컨벤션이나 CI 정책은 추가하지 않는다.

## 작업 범위

### 포함

- 한국어 리뷰, chill 강도, Draft 제외와 main 및 develop 대상 추가 커밋 리뷰 설정.
- Swift, React, Node 도구, GitHub 설정과 문서의 경로별 리뷰 지침 및 기존 컨벤션 파일 연결.
- 생성물과 로컬 증적 제외 및 요약 댓글 설정과 불필요한 자동화 비활성화.
- 새 설정 파일이 기존 CI에서 미분류 오류를 일으키지 않도록 소비 관계에 따른 분류와 회귀 검증.
- 앱 연결 범위 확인, 적용 설정과 실제 PR 리뷰 검증 방법 문서화.
- 사용자 요청에 따른 커밋과 push 및 develop 대상 PR 작성.

### 제외

- merge 및 원격 보호 규칙 변경.
- 새 이슈, 코딩 컨벤션, 린터 설치와 앱 기능 변경.
- 저장소 전체 접근이나 유료 구독, 리뷰를 필수 병합 조건으로 강제하는 정책.

## 설계 결정

- 루트 .coderabbit.yaml에서 리뷰 설정을 관리하고 docs/code-review.md에서 사용과 연결 절차를 설명한다.
- Keeply의 Electron 지침과 pnpm 잠금 파일 제외는 이식하지 않는다. Ttak의 실제 경로와 기존 규칙을 사용한다.
- knowledge_base.code_guidelines는 공통 규칙을 전체에, Swift와 웹 규칙을 해당 앱 경로에만 적용한다.
- PR 본문을 자동 수정하지 않고 요약을 walkthrough 댓글에 표시한다. 라벨, 리뷰어, 자동 승인과 추가 사전 병합 검사는 끈다.
- CI의 이벤트와 워크플로는 유지한다. 리뷰 앱이 소비하는 .coderabbit.yaml은 무거운 검사 대상에서 명시적으로 제외하고 Changes와 CI Result는 유지한다.
- 앱 연결은 ttak-app/ttak-workspace 하나로 제한한다. 실제 권한 동의와 연결 및 PR 리뷰를 확인하기 전까지 원격 완료 조건은 대기다.
- 상태와 데이터 흐름은 앱에 변경이 없어 N/A다. 설치 전이나 리뷰 실패 상태를 성공으로 처리하지 않는다.

## 완료 조건

- AC-1: Keeply를 참고한 YAML이 공식 스키마를 통과하고 한국어, chill, Draft 제외, 대상 브랜치와 추가 커밋 리뷰가 설정된다.
- AC-2: 기존 공통 규칙과 Swift 및 웹 규칙이 올바른 경로에 연결되고 Electron과 다른 언어의 규칙을 혼용하지 않는다.
- AC-3: 생성물과 로컬 증적은 제외하되 실제 소스와 잠금 파일은 리뷰 대상이며 불필요한 자동화가 꺼져 있다.
- AC-4: .coderabbit.yaml 단독 변경은 CI 분류 오류 없이 앱 빌드와 도구 테스트를 생략하고 Changes 및 CI Result로 판정한다. 다른 변경과 함께 있으면 필요한 소비 대상 검사를 유지한다.
- AC-5: 연결과 사용 문서가 로컬 검증과 원격 미검증을 구분하고 하네스 구조 및 diff 검사가 통과한다.
- AC-6: GitHub 앱이 해당 저장소에 연결되고 실제 PR에서 적용 설정과 한국어 리뷰, 경로별 지침 및 Draft와 추가 커밋 동작을 확인한다.
