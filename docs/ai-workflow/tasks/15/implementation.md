## 검증 화면의 임시 동작

다음 동작은 최소 검증을 위한 구현 선택이며 제품 UX 확정으로 일반화하지 않는다.

- 모델 가용성은 창 열기와 환경 새로 확인에서 갱신한다. 모델 사용 불가를 모의 성공으로 대체하지 않는다.
- 미리 알림 접근 및 목록 조회 버튼을 눌렀을 때만 권한을 요청한다. 분석 자체는 권한 요청이나 저장을 실행하지 않는다.
- 목록을 먼저 조회하면 실제 후보를 모델에 전달한다. 목록 없이 분석하면 목록 추천이 미선택이고, 이후 조회와 직접 선택이 필요하다.
- 입력을 수정하거나 이미지를 변경하면 기존 초안을 비운다. 분석 중에는 편집을 잠그고 분석 취소를 제공한다. 영구 복원은 구현하지 않는다.
- 입력의 날짜 기준은 분석 시작 시점의 로컬 날짜, 달력과 시간대로 고정한다. 초안에는 `yyyy-MM-dd`와 선택적인 `HH:mm`을 사용하고 저장 전에 유효성을 다시 검사한다.
- 날짜 충돌은 명시적인 날짜 확인 버튼을 요구한다. 날짜나 목록을 확인하지 않은 포함 항목은 일괄 저장을 막는다. 제외한 항목은 저장하지 않는다.
- Foundation Models의 구조화 출력은 형식 보조다. 의미가 맞는지는 실제 합성 입력 결과와 사용자 편집에서 별도로 확인해야 한다.
- 초기 실제 추출에서 지침의 예시를 일정으로 혼동하고 시각을 임의 생성했다. 구체 일정 예시를 지침에서 제거하고 필드 설명과 일정 분리 지침을 보완했다. 시각은 숫자 생성 대신 입력에 실제 존재하는 표현을 코드로 대조하고 정규화한다. 모호한 시각이나 종료만 있는 표현은 정확한 시작 시각으로 바꾸지 않는다.
- 시각 정규화는 명확한 오전과 오후 표현 및 24시간제 숫자 표현을 중심으로 한다. 아침, 저녁과 밤 표현의 세부 날짜 경계는 임의 확정하지 않고 원문과 확인 안내를 남긴다. 서브 검토에서 밤 12시가 정오로 바뀌는 회귀를 발견해 자동 변환을 막고 회귀 테스트를 추가했다.
- OCR 자료와 보조 설명을 구분해서 전달한다. 실제 이미지에서 보조 설명을 한 번의 추출 호출로 처리했을 때 선택이 무시되어, 보조 설명이 있는 경우에만 후보 선택용 모델 호출을 추가했다. 후보 밖 인덱스와 선택 실패는 오류이며 전체 후보로 되돌리지 않는다.
- 미리 알림 저장은 항목마다 commit한다. 외부 저장 API의 오류가 실제 무쓰기를 보장하지 않으므로 해당 항목은 결과 불명으로 표기한다. 이후 항목을 실행하지 않고 같은 입력의 분석과 재등록을 잠근다.
- 사용자가 미리 알림 앱을 확인한 뒤 새 입력을 시작할 수 있다. 자동 재시도나 부분 저장 복구 정책을 구현하지 않았다. 새 입력 후 중복 등록 여부까지 보장하는 영구 중복 제거 기능은 아니다.
- 저장 오류 뒤에는 EventKit 저장소의 미확정 로컬 변경을 reset으로 폐기한다. 이미 외부에 저장되었는지는 이 동작으로 확정하지 않는다. [Apple reset 문서](https://developer.apple.com/documentation/eventkit/ekeventstore/reset%28%29)
- 전체 성공에서만 입력과 이미지 및 초안을 비우고 등록 완료를 표시한다. 저장된 알림을 자동 수정하거나 삭제하지 않는다. 사전 알림과 캘린더 이벤트를 생성하지 않는다.

## 자동 검사 근거

첫 구현 단계에서 `npm run macos:build`가 성공했다. 이후 부모 검토에서 시각의 원문 근거와 숫자 형식 검증을 보완했으므로 최종 포맷, 빌드와 테스트 결과는 로컬 `.tmp/ai-workflow/tasks/15/`의 최종 검증 기록을 우선한다. 단위 테스트 수는 최종 로그의 실제 집계를 기준으로 보고한다.

명령:

```sh
npm run format:check:macos
npm run macos:build
npm run macos:test
npm run workflow:harness-check
```

단위 테스트는 합성 데이터와 대체 서비스를 사용한다. 실제 Foundation Models 추출 품질, Vision 실행 결과, EventKit 권한과 개인 목록 접근을 테스트 통과에 포함하지 않는다.

## 실제 서비스 관찰

- 환경: Apple Silicon, macOS 27.0.1, Xcode 27.1. 최소 지원 macOS 26에서의 실제 모델 응답과 UI 동작은 아직 확인하지 않았다.
- 시스템 모델 가용성 available, 한국어 지원 true, Vision accurate 경로의 ko-KR 지원을 확인했다.
- 날짜 기준을 2026-10-27, Asia/Seoul로 고정한 합성 예제에서 단건의 다음 날 오전 9시, 같은 날의 런닝과 저녁 회식 분리, 내일과 모레의 서로 다른 날짜를 관찰했다. 이 소규모 사례를 일반 정확도 보장으로 해석하지 않는다.
- 종료 시각만 있는 합성 대화에서 시작 시각을 비우고 장소와 종료 정보를 메모에 보존하는 결과를 확인했다. 제목의 간결함, 부가 정보 보존과 목록 추천의 일반 품질은 후속 관찰이 필요하다.
- 초기 Swift 해석 실행에서는 Vision nilError 또는 e5rtError가 발생했다. 동일한 앱 OCR 서비스를 컴파일한 실행 파일에서는 합성 이미지의 한글 5줄을 읽었다. 성공 실행은 약 31.5초였으며 성능 목표나 전형적인 처리 시간으로 취급하지 않는다.
- 동일한 합성 이미지에서 보조 설명 없이 일정 두 건을 추출하고, `이 중 회의만 등록해줘` 요청에서는 회의 한 건만 반환하는 최종 서비스 결과를 확인했다. 실제 저장은 실행하지 않았다.
- UI 제어 도구의 로컬 앱 접근은 timeout으로 실패했다. 메뉴바 화면, 파일 선택과 Cmd+V를 실제 조작해 검증한 것으로 보고하지 않는다.
- 서비스 검증은 실제 앱과 동일한 Swift 소스를 사용한 별도 실행 파일에서 수행했다. 앱 번들의 sandbox, 권한, 화면 상태 및 실제 미리 알림 저장을 대신 검증하지 않는다.
- 로그와 합성 이미지 및 재현용 probe는 Git에서 제외한 `.tmp/ai-workflow/tasks/15/`에 둔다. 초기 실패와 수정 후 결과를 구분한다.

## 실제 Mac 수동 확인

테스트 목록은 사용자가 직접 선택한다. 자동 테스트 준비 과정으로 목록이나 항목을 생성하지 않는다. 개인 일정과 캡처를 로그 또는 Git에 기록하지 않는다.

1. 로컬 앱을 실행하고 모델 가용성을 확인한다. 모델 사용 불가 상태는 실패 원인을 기록한다.
2. 합성 입력 `내일 오전 9시 회의`를 분석해 항목 수, 제목, 날짜와 시각을 확인한다. 분석만으로 미리 알림이 생성되지 않는지 확인한다.
3. 서로 다른 날짜의 복수 일정과 모호한 시각을 분석한다. 모호한 값이 정확한 시각으로 확정되지 않는지, 목록 후보 밖 ID가 미선택인지 확인한다.
4. 미리 알림 접근 및 목록 조회를 선택하고 사용자가 권한을 허용하거나 거부한다. 거부 상태의 문구와 입력 보존을 확인한다. 허용한 경우 기존 쓰기 가능 목록을 확인한다.
5. 테스트용 목록을 선택하고 초안 제목과 시각을 수정한 뒤 등록 버튼을 누른다. Apple 미리 알림 앱에서 선택 목록과 최종값을 대조한다. 날짜 저장과 실제 알림 발생은 별도 확인 사항이다.
6. 합성 이미지 파일을 선택하고 미리보기, 삭제, 파일 선택 취소를 확인한다. 이미지 단독 및 보조 설명으로 분석한다.
7. 같은 합성 이미지를 복사해 입력창의 Cmd+V와 이미지 붙여넣기 버튼을 각각 확인한다. OCR 결과는 텍스트와 같은 편집 및 저장 경로를 사용해야 한다.
8. 분석 취소, 결과 취소와 반복 버튼 실행을 확인한다. 취소는 저장하지 않고 원래 입력을 유지해야 한다.
9. 실제 사용자 데이터를 손상시키는 저장 실패 실험은 하지 않는다. 전체 실패와 부분 결과 불명 및 재등록 차단은 대체 저장 서비스의 자동 테스트로 확인한다.

## 남은 한계

- 모델의 실제 한국어 의미 추출은 빌드 성공과 별개다. 합성 입력의 실제 관찰 결과로 품질 제약을 기록해야 한다.
- 합성 이미지의 OCR 단독 서비스 실행과 메뉴바 UI의 파일 선택 및 붙여넣기는 다른 검증이다. UI 미실행을 서비스 결과로 대체하지 않는다.
- 실제 EventKit 권한, 쓰기 가능 목록 조회와 저장 대조는 사용자 선택과 수동 확인이 필요하다. 아직 실행하지 않았다면 AC-3은 미검증이다.
- 창 닫기 및 재실행 복원, 원본 이미지 영구 저장, 부분 저장 복구와 자동 중복 제거는 포함하지 않았다.
- 파일 크기와 처리 시간의 임의 제한을 제품 정책으로 추가하지 않았다. 매우 큰 이미지에 대한 UX와 메모리 검증은 별도다.


## 2차 텍스트 가드

1차 커밋 `381b4e1` 이후 원문 근거 및 필드 귀속 가드와 최대 한 번의 행동 재분석을 추가했다. 상세 구현, 실제 모델 비교 조건과 남은 한계는 [2차 결과](round2-results.md)를 따른다. 1차 문서의 전체 입력 시각 대조를 일정별 구간 대조로 강화했으며 UI와 실제 저장의 미검증 범위는 유지한다.
