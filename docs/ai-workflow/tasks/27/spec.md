# 작업 명세: ScheduleResultPanel 일정 결과 패널 구현

## 연결 정보

- 이슈: #27 / https://github.com/ttak-app/ttak-workspace/issues/27
- 브랜치: feat/schedule-result-panel/#27
- specRevision: 9

## 목적

기존 편집 카드를 묶어 일정 개수와 전체 취소 및 등록 액션을 제공한다.

## 작업 범위

### 포함

- ScheduleResultItem 목록과 최대 너비 500pt의 ScheduleResultPanel
- 제외에 따른 개수 갱신, 빈 상태, 등록 검증과 외부 콜백
- Debug 갤러리의 단일, 복수, 빈 결과 및 모의 액션

### 제외

- AI 및 OCR, 권한과 목록 조회, 실제 미리 알림 저장

## 설계 결정

- 초안은 외부 소유 Binding 배열로 전달한다. 제외는 안정 UUID로 isExcluded만 변경한다.
- 취소는 콜백만 호출한다. 원래 입력 보존과 결과 닫기는 호출부 책임이다.
- 등록은 제외하지 않은 최종 초안을 전달한다. View에서 서비스는 생성하지 않는다.
- 사용자 합의: 전체 제외 시 빈 안내와 비활성 0개 등록을 표시한다. 기존 초안 검증 오류가 있으면 등록을 비활성화한다. 시각 미지정은 기존 검증대로 허용한다.
- 기존 카드 재사용과 동일한 중립 Liquid Glass 스타일을 적용한다.

## 완료 조건

- AC-1: 단일 및 복수 편집 카드를 표시하고 편집과 제외에 따라 개수 및 등록 대상이 갱신된다.
- AC-2: 빈 결과와 전체 제외 시 빈 안내 및 비활성 0개 등록을 표시한다. 검증 오류가 남으면 등록 불가다.
- AC-3: 취소와 등록은 외부 콜백으로 전달하며 실제 저장 및 원래 입력 초기화를 하지 않는다.
- AC-4: 갤러리에서 단일, 복수, 빈 결과와 모의 액션을 확인할 수 있다.

- AC-5: 갤러리에서 입력, 모의 분석 진행, 결과 편집과 제외, 취소 후 입력 보존, 모의 등록과 완료 초기화를 확인할 수 있다.

## 미결정 사항

- 없음. 실제 서비스 연결과 저장 수명은 별도 작업이다.

## 후속 합의

입력과 동일한 500pt 너비에서 날짜, 시각, 목록을 한 줄로 유지하도록 기존 편집 카드의 필드 너비와 간격을 줄인다. 날짜 132pt, 시각 110pt, 목록은 최소 100pt와 남은 공간을 사용한다. 글자 크기와 세로 클릭 영역은 유지하고 긴 선택값은 말줄임한다. 더 좁은 공간에서는 기존 세로 배치로 전환한다.

패널의 중복 검증 안내 문구는 제거한다. 항목별 검증 안내와 등록 버튼 비활성화 조건은 유지한다.

## 갤러리 프로토타입 추가 합의

패널 작업 커밋 후 사용자 요청으로 갤러리에 입력부터 확인과 편집, 모의 등록까지 연결하는 프로토타입을 추가한다. #23 브랜치의 ScheduleStatusView를 재사용한다. 입력과 무관한 합성 일정 2개를 반환함을 표시하고, 결과 확인 중에는 입력을 비활성화한다. 취소 시 입력과 이미지를 유지하고 모의 등록 완료 시 초기화한다. 진행은 취소 가능한 View task로 흉내 내며 실제 서비스는 호출하지 않는다.


사용자 요청으로 프로토타입 본문은 밝은 시스템 배경과 light 외관을 사용해 가독성을 확인한다.

사용자 합의: 모의 등록 완료 안내는 3초 뒤 자동으로 사라진다. phase가 바뀌거나 View가 사라지면 대기를 취소하며, 새 입력 내용은 자동 숨김 시 초기화하지 않는다.

결과 확인 및 등록 중에는 첨부 카드를 숨기고 이미지 데이터는 보존한다. 사용자 후속 요청으로 원본 이미지 보기 버튼과 팝오버는 제공하지 않는다. 취소하면 기존 첨부 카드가 복원되고 등록 완료 시 데이터가 초기화된다. ScheduleComposer의 showsAttachment는 기본 true로 기존 호출부 표시를 유지한다.

이미지 붙여넣기 실패 보고에 따라 편집기가 Command V를 직접 paste로 전달한다. 비활성 입력에서는 소비하지 않으며 이미지가 아닌 내용은 기존 네이티브 텍스트 붙여넣기로 전달한다. 단축키 전달 회귀 테스트를 추가한다.

스크린샷 전용 클립보드에서 네이티브 편집기의 붙여넣기 허용 대상에 PNG와 TIFF 및 파일 URL을 추가한다. 실제 갤러리에서 Command V 후 붙여넣은 이미지 미리보기와 삭제 버튼, 분석 버튼 활성화를 확인했다. 관련 회귀 테스트 포함 147개 테스트가 통과했다.
