# [Feat] 입력 및 일정 결과 확인 화면 상태 연결

## ✅ Tasks (To-Do)

- [ ] 입력, 분석 진행, 결과 확인, 취소 및 오류 상태를 소유하는 최소 상태 모델 구성
- [ ] 입력 컴포넌트와 진행과 오류 안내, 결과 편집 패널을 하나의 화면 흐름으로 연결
- [ ] 분석 진행 중 중복 요청 방지 및 task 취소와 화면 수명 처리
- [ ] 결과 취소 후 텍스트와 이미지 첨부 보존
- [ ] 등록된 초안을 후속 저장 경계에 전달하되 실제 EventKit 저장은 수행하지 않음
- [ ] 주요 상태 전이와 입력 보존을 합성 데이터 기반으로 검증

## 📝 Description

대상 영역: macOS

현재 준비된 입력, 상태 안내, 일정 결과 편집 컴포넌트를 실제 앱 흐름으로 연결합니다. 이 이슈는 화면 상태와 컴포넌트 전이까지 다루고, OCR과 AI 분석과 미리 알림 권한/목록 및 EventKit 저장은 후속 이슈에서 연결합니다. 임시 분석 응답을 사용하는 경우 실제 서비스가 연결되지 않았음을 개발 흐름에서 구분합니다.

### 완료 조건

- 입력 → 분석 진행 → 결과 확인 흐름이 이어집니다.
- 결과 취소 시 원래 입력과 첨부 이미지를 보존합니다.
- 중복 분석을 방지하고 취소된 비동기 작업이 이후 상태를 덮어쓰지 않습니다.
- 빈 결과와 분석 오류를 구분해 표시하며 오류 상태에서는 등록하지 않습니다.
- 편집된 유효 초안은 후속 저장 경계에 전달하고 이 이슈에서는 EventKit에 쓰지 않습니다.
