# 작업 명세: Gemini 일정 분석 및 결과 화면 연결

## 연결 정보

- 이슈: #30 / https://github.com/ttak-app/ttak-workspace/issues/30
- 브랜치: feat/gemini-analysis/#30
- specRevision: 1
- 선행 작업: #29 입력 및 일정 결과 확인 화면 상태 연결, #15 핵심 기술 검증

## 목적

#15에서 검증한 Gemini 분석기(`ScheduleAnalyzer`)를 #29의 `ScheduleFlowModel` 주입 경계에 연결한다. 텍스트 입력의 실제 분석 결과를 일정 편집 패널에 표시하고, 실패 시 원인을 구분해 안내하며 입력을 보존한다. 또한 #29 리뷰에서 나온 확인 사항에 따라 분석이 응답하지 않을 때 패널이 계속 잠기지 않도록 타임아웃과 취소 경로를 함께 다룬다.

## 작업 범위

### 포함

- `ScheduleFlowModel.Analyze` 클로저에 `ScheduleAnalyzer.analyze(text:context:)`를 호출하는 어댑터를 연결하고, 개발용 흐름의 합성 일정을 실제 분석 결과로 교체한다.
- 분석 결과를 `ScheduleDraft` 일정 초안으로 결과 패널에 전달한다.
- 일정 없음(`AnalysisFailure.emptyResult`)을 빈 결과 상태로 변환해 분석 실패와 구분한다.
- API 키 미설정, 네트워크 오류, 서버 오류, 응답 이상, 시간 초과를 사용자에게 한국어로 구분해 안내하고 재시도를 연결한다.
- 분석 전체에 상한 시간을 두고 초과 시 작업을 취소하며 실패 상태로 전환한다.
- 분석 중 취소 버튼을 제공하고, 취소하면 입력을 유지한 채 입력 상태로 돌아간다.
- 분석 실패와 취소 후 기존 입력을 유지하고 수정 또는 재분석을 허용한다.
- 합성 응답으로 상태 전이를 검증하고, 개발 환경에서 실제 Gemini 호출 결과를 기록한다.

### 제외

- 이미지 OCR 연동
- Apple 미리 알림 권한 요청, 목록 조회 및 저장
- 배포용 API 키 보호 방식의 확정과 구현
- 릴리스 빌드(`MenuBarExtra`)의 화면 교체

## 결정 사항

아래 항목은 사용자와 확정했다.

| 항목 | 추천안 | 상태 |
| --- | --- | --- |
| 이미지만 첨부된 입력 | OCR이 제외 범위이므로 분석을 막고 안내한다 | 확정 |
| 저장 목록(`lists`) | 미리 알림 연동 전까지 임시 목록을 유지하고 후속 이슈에서 교체한다 | 확정 |
| 분석 전체 타임아웃 | 30초. 재시도(추출 최대 2회와 선택 1회)를 고려한다 | 확정 |
| 연결 범위 | DEBUG 패널(`TtakApp`의 `flowModel`)까지만 연결한다 | 확정 |

## 완료 조건

- AC-1: 텍스트 입력을 분석하면 실제 Gemini 분석 결과가 일정 편집 패널에 표시되며 입력과 무관한 합성 일정은 사용하지 않는다.
- AC-2: 분석 진행 중에는 진행이 표시되고 중복 분석이 실행되지 않는다.
- AC-3: 일정 없음과 분석 실패가 서로 다른 상태로 표시되고, API 키 미설정과 네트워크 오류를 사용자가 구분해 확인할 수 있다.
- AC-4: 분석 실패나 일정 없음 이후 기존 입력이 유지되고 다시 분석할 수 있다.
- AC-5: 응답이 없을 때 정해진 시간 뒤 분석이 취소되고 실패로 안내되며, 분석 중 취소 버튼으로 입력 상태로 돌아갈 수 있고 취소된 이전 작업은 이후 상태를 덮어쓰지 않는다.
- AC-6: 합성 응답 기반 테스트로 성공, 일정 없음, 오류 유형, 시간 초과, 취소, 중복 요청과 입력 보존을 검증한다.
- AC-7: 개발 환경에서 실제 Gemini 호출을 확인하고 결과를 기록한다.

## 검증 방법

- `npm run format:macos` 후 `npm run format:check:macos`
- macOS 빌드와 `ScheduleFlowModelTests`를 포함한 관련 테스트 실행
- `.env`의 `GEMINI_API_KEY`로 실제 입력(예: 9시에 런닝, 11시에 점심)을 분석해 결과 확인
- 키 미설정과 네트워크 차단 상태에서 안내 문구와 재시도 확인
- 실제 호출 결과는 로컬 증적과 PR에 기록한다. API 키 값은 기록하지 않는다.
