# 진행과 오류 및 접근 안내

- specRevision: 2

## 범위

기존 ScheduleMessageView는 설명 본문으로 재사용한다. ScheduleStatusView는 진행, 정보, 경고, 실패, 성공 표현과 선택적 외부 액션을 제공한다. 실제 앱 서비스는 연결하지 않고 Debug 갤러리에 합성 상태 15개를 추가한다.

문구와 버튼은 검토용 제안이다. 권한 요청 시점, 앱 흐름, 복구와 중복 방지 정책은 확정하지 않는다.

## 완료 조건

- AC-1: 분석 진행, OCR 실패, 분석 실패, 모델 사용 불가, 일정 없음을 구분한다.
- AC-2: 권한 미결정과 거부 또는 철회, 목록 진행과 목록 없음 및 조회 실패를 구분한다.
- AC-3: 저장 진행, 전체 성공과 실패, 부분 성공과 결과 확인 필요를 구분한다.
- AC-4: 샘플 버튼은 로컬 기록만 변경하며 외부 서비스나 개인 데이터를 사용하지 않는다.
- AC-5: 진행 표시와 아이콘 및 접근성 이름을 제공하고 긴 설명과 액션 없는 상태를 지원한다.
- AC-6: Swift 포맷, 빌드, 기존 테스트와 실제 갤러리 실행을 검증한다.

## 후속 합의

안내 컴포넌트와 갤러리 본문은 입력 컴포넌트와 동일한 최대 너비 500pt를 사용한다. 사용자 요청에 따라 일정 결과 편집 카드와 해당 갤러리 본문도 같은 너비로 맞춘다. 기존 필드 검증 로직은 유지한다. 실제 앱에서 입력창 아래에 배치하는 것은 제안이며 서비스 연결 범위에 포함하지 않는다.
