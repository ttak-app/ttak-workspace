TTAK / BRAND FOUNDATIONS

브랜드만 함께, 기본 외관은 시스템에.

웹과 앱이 공유할 최소한의 브랜드 기준입니다. 앱은 Apple 기본 컴포넌트를 우선 사용하고, Ttak을 표현할 때 필요한 색상만 선택해서 적용합니다.

공통 토큰 7개 / 컬러 6개 + 로고 그라디언트 1개

브랜드와 로고 컬러

coral과 orange는 브랜드 표현, strong은 강조, tint는 브랜드 콘텐츠의 옅은 배경에 사용합니다. 기본 컨트롤 전체를 이 색으로 덮어쓰지 않습니다.

color.brand.coral

#D75D57

브랜드 coral. 브랜드 표현에 사용하며 기본 컨트롤 색을 일괄 대체하지 않음

color.brand.orange

#E39343

브랜드 orange. 브랜드 표현용

color.brand.strong

#A94F27

강조가 필요한 브랜드 텍스트와 선택적 tint 후보

color.brand.tint

#FFF3E9

브랜드 콘텐츠의 옅은 배경. 시스템 팝오버와 Liquid Glass 배경에는 기본 적용하지 않음

웹 로고의 115도 그라디언트. 앱은 두 로고 색상을 참조하고 좌표는 별도 검토

로고 색상과 그라디언트는 일반 본문용 색상이 아닙니다. 브랜드 강조색도 실제 배경과 밝고 어두운 외관에서 대비를 확인한 뒤 사용합니다.

앱에서 시스템에 맡기는 것

항목 적용 기준
텍스트와 폰트 시스템 텍스트 스타일과 primary / secondary 우선
배경과 상태색 시스템의 의미 색상과 기본 컨트롤 스타일 우선
유리 효과와 그림자 Apple 기본 컴포넌트와 Liquid Glass 활용
간격과 모서리 기본 컴포넌트 규격 우선. 반복 사용 근거가 생길 때만 공통화 검토
모션 기본 동작과 접근성 설정을 따름

이 표는 적용 기준 설명이며, 브라우저에서 네이티브 Liquid Glass를 재현한 화면은 아닙니다.

랜딩의 반응형 글자 크기, 레이아웃, 블러와 그림자는 해당 웹 스타일에서 관리합니다.
관리 원본: design-system/tokens.json / 재생성: npm run tokens:build
이 페이지의 배치와 설명용 스타일은 제품 공통 토큰이 아닙니다.
