# macOS 개발 경계와 검증

기존 기획의 Swift·SwiftUI, macOS 26+, Foundation Models, EventKit 방향을 기준으로 한다.
Foundation Models 한국어 품질과 실제 미리 알림 저장은 아직 검증 전이다.
이 문서는 코딩 스타일이나 새로운 아키텍처를 확정하지 않는다.

## 검토할 경계

- 화면과 입력 상태, 분석 중 상태, 편집 가능한 일정 초안, 저장 결과의 수명을 구분한다.
- SwiftUI UI 상태 갱신의 actor 격리를 확인하고, 분석·조회 같은 비동기 작업의 취소·재진입·중복 실행을 검토한다.
  모든 객체를 일괄 `@MainActor`로 만들거나 특정 패턴을 강제하지 않는다.
- 메뉴바 창의 포커스·열기·닫기·분석 결과 확장·입력 보존은 실제 macOS에서 확인한다.
- 모델 응답은 미검증 입력이다. 항목·제목·날짜·시간·기존 목록 ID를 코드에서 검증한다.
- 상대 날짜의 기준 시점·달력·시간대를 명시한다. ‘저녁’ 같은 모호한 표현과 미정 정책을 임의로 확정하지 않는다.
- 미리보기·수정·취소 중 EventKit 저장을 수행하지 않는다. 확인 후 쓰기 가능한 목록을 다시 검증한다.
- 권한 거부·변경, 모델 사용 불가, 분석 실패, 부분 저장 성공, 재시도와 중복 저장을 검토한다.
- 테스트는 합성 데이터나 mock을 우선한다. 사용자 미리 알림 생성·삭제를 테스트 준비 동작으로 실행하지 않는다.
- iOS 시뮬레이터·UIKit 기준으로 메뉴바 앱을 검증하지 않는다. 웹 빌드는 Swift 검증을 대신하지 않는다.

## 실행 환경

`npm run macos:build`는 전체 Xcode 26 이상을 확인한 후 현재 Xcode 프로젝트를
서명 없이 빌드한다. 산출물은 Git에서 제외하는 `.tmp/xcode-derived-data`에 둔다.
`npm run macos:test`는 먼저 선택한 공유 Ttak 스킴에 실행할 테스트 타깃·플랜이 있는지 확인한다.
타깃이 없거나 Xcode가 없으면 non-zero로 종료하며 실제 테스트 통과가 아니다.
새 테스트 타깃을 하네스가 자동 생성하지 않는다.

실기기 검증에서는 macOS·Xcode 버전, 모델 활성 상태, 미리 알림 권한과 테스트 대상을 기록한다.
코드 서명·공증·배포 설정은 별도 배포 작업이다.
