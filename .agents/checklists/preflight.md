# 시작 확인

[공통 작업 흐름](../../docs/rules/ai-workflow.md)을 적용한다.

- 요청 종류·합의한 범위·기존 권한을 확인한다. 읽기 전용이면 파일을 쓰지 않는다.
- 현재 저장소·브랜치·사용자 변경을 확인하고 연결 이슈·명세를 읽는다.
- 재개 시 resume과 로컬 증적의 freshness를 확인한다. 기록 부재를 완료로 보지 않는다.
- 실제 비교 기준 ref를 명시하고 자동 fetch·브랜치 생성·스태시·커밋을 하지 않는다.
- macOS 작업은 Xcode·테스트 타깃·모델/권한 검증 가능 범위를 확인한다.
- 구현 전 변경 범위와 파일을 설명한다. 이미 합의된 세부 사항은 다시 질문하지 않는다.
