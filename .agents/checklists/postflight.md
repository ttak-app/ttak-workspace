# 완료 확인

[공통 작업 흐름](../../docs/rules/ai-workflow.md)의 변경별 검증을 적용한다.

- 하네스 구조 검사와 변경에 해당하는 실제 명령을 실행·기록한다.
- Swift 변경에 웹 검사만 수행하거나 Xcode 부재를 성공 처리하지 않는다.
- 새 파일·staged·unstaged까지 범위에 포함한다. 의도하지 않은 앱·CI·GitHub 설정 변경이 없는지 확인한다.
- 기본 기준과 사용자 관점으로 리뷰하고 미해결 결함·환경 한계를 남긴다.
- 검증 이후 코드·명세·환경·기준 ref가 바뀌면 필요한 결과를 다시 확인한다.
- 커밋·게시 전 readiness와 권한을 구분한다. 설정 작업만으로 커밋·push·PR을 자동 수행하지 않는다.

- 수정한 경로의 [코딩 컨벤션](../../docs/rules/coding-convention.md)과 게시물의 [Git 컨벤션](../../docs/rules/git-convention.md) 준수 여부를 확인한다. 자동 검사되지 않는 문서 규칙은 수동 검토했다고 구분한다.
